## What This Project Is

Community Navigator is a local-first, privacy-first tool for communities to represent people, places, organizations, skills, needs, and their relationships as a living 3D graph. Its intended workflow is to help a community explore its own network and find paths from a need to people or resources that can address it. The architecture keeps data modeling, validation, permissions, event storage, and graph queries in a Rust core compiled to WebAssembly, while the TypeScript application renders only permission-filtered projections. Group structure, attributes, themes, and stories are intended to be versioned data rather than community-specific application forks. Sources: `CLAUDE.md` (Mission, Requirements, Architecture stances), `docs/THE_STORY.md`, `docs/adr/ADR-001-domain-model.md`, and `docs/adr/ADR-003-wasm-boundary.md`.

The current v0.1.0 target is a facilitator-run convention-arc pilot with an acceptance bar of actual usage at pilot scale (roughly 150 expected, 300 max signups). The pilot path is consented intake through direct in-app entry plus a QR sealed-envelope relay (static form on GitHub Pages, client-side encryption to the facilitator public key, minimal Cloudflare Workers + KV ciphertext relay, facilitator pending-review queue), rendering a participant and committee graph, need-to-solution routing, and authored stories. August internal pilots run on the normal app build; the offline single-file snapshot is resequenced after the intake pipeline and targets the convention build (convention 2026-09-14). Personal mode, identity, deep accessibility, and governance tooling are deferred past the convention arc. Sources: `DECISIONS.md` D-050, D-052, D-053, D-056, `HANDOFF.md` (State of play), and `PLAN_1.0.md`.
